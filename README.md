# Testes e Comparação de Distribuições Linux

## Sobre o projeto

Este projeto tem como objetivo realizar testes práticos com diferentes distribuições Linux, analisando suas características, ambientes, ferramentas e funcionalidades voltadas principalmente ao desenvolvimento de software.

As distribuições escolhidas para os testes foram **Ubuntu** e **Fedora**, ambas amplamente utilizadas em ambientes de desenvolvimento e com suporte a diversas linguagens de programação, ferramentas e bibliotecas.

Os testes serão realizados em máquinas virtuais, permitindo analisar as distribuições em um ambiente controlado, sem modificar o sistema operacional principal dos computadores utilizados.

---

## Objetivos

### Objetivo geral

Testar e analisar diferentes distribuições Linux, observando suas características, facilidade de uso, recursos disponíveis e adequação para atividades de desenvolvimento.

### Objetivos específicos

- Pesquisar a história e as principais características das distribuições;
- Identificar o perfil de uso de cada distribuição;
- Verificar os requisitos mínimos de instalação;
- Analisar os ambientes gráficos disponíveis;
- Instalar as distribuições em máquinas virtuais;
- Testar comandos básicos do terminal;
- Testar navegação e criação de diretórios e arquivos;
- Verificar a instalação e execução de programas;
- Testar a execução de códigos em Python e C;
- Registrar problemas encontrados durante os testes;
- Comparar os resultados obtidos;
- Documentar todo o processo realizado.

---

## Distribuições escolhidas

### Ubuntu

O **Ubuntu** é uma distribuição Linux baseada no Debian e conhecida pela facilidade de uso, ampla comunidade e grande quantidade de documentação disponível.

Foi escolhido por ser uma distribuição bastante utilizada tanto por usuários iniciantes quanto em ambientes de desenvolvimento. Possui suporte a diversas linguagens de programação, IDEs, bibliotecas e ferramentas necessárias para desenvolvimento de software.

### Fedora

O **Fedora** é uma distribuição Linux mantida pela comunidade com apoio da Red Hat. A distribuição possui foco em tecnologias recentes e oferece um ambiente adequado para desenvolvimento e experimentação.

Assim como o Ubuntu, o Fedora possui suporte a diversas linguagens de programação e ferramentas de desenvolvimento, permitindo realizar testes com diferentes tecnologias.

### Justificativa da escolha

Ubuntu e Fedora foram escolhidos por apresentarem boa compatibilidade com ferramentas de desenvolvimento e por serem distribuições amplamente utilizadas. A comparação entre as duas também permite observar diferentes abordagens dentro do ecossistema Linux, especialmente em relação ao gerenciamento de pacotes, configuração do sistema e ambiente de desenvolvimento.

---

## Virtualização

Para realizar os testes, será utilizado um ambiente de virtualização, evitando a necessidade de instalar as distribuições diretamente nos computadores.

A virtualização permite criar máquinas virtuais independentes, nas quais os sistemas operacionais podem ser instalados e testados de forma segura.

### Ferramenta utilizada

- VMware

A utilização de máquinas virtuais permite manter o sistema operacional principal intacto e facilita a repetição dos testes em diferentes distribuições.

## Etapas do projeto

O desenvolvimento do projeto foi organizado nas seguintes etapas:

### 1. Planejamento

- Escolha das distribuições Linux;
- Definição do nicho e objetivo das distribuições;
- Pesquisa dos requisitos mínimos;
- Escolha da ferramenta de virtualização.

### 2. Pesquisa

Para cada distribuição serão pesquisados:

- Histórico;
- Características principais;
- Perfil de uso;
- Principais recursos;
- Requisitos do sistema;
- Ambiente gráfico;
- Ferramentas de desenvolvimento;
- Gerenciamento de pacotes.

### 3. Instalação

As distribuições serão instaladas em máquinas virtuais.

Durante essa etapa serão realizados:

- Instalação do VMware;
- Criação das máquinas virtuais;
- Instalação do Ubuntu;
- Instalação do Fedora;
- Configuração inicial dos sistemas;
- Registro de possíveis problemas encontrados.

### 4. Testes e demonstração

Após a instalação, serão realizados testes práticos para verificar o funcionamento dos sistemas.

Entre os testes estão:

- Execução de comandos básicos do terminal;
- Criação de diretórios;
- Navegação entre pastas;
- Criação e manipulação de arquivos;
- Abertura de programas;
- Instalação de novos programas;
- Execução de código Python;
- Execução de código C;
- Testes relacionados ao ambiente de desenvolvimento.

Os resultados dos testes serão registrados para permitir a comparação entre as distribuições.

### 5. Relatório

Ao final dos testes, serão documentados:

- Características de cada distribuição;
- Perfil de utilização;
- Processo de instalação;
- Ambiente de virtualização;
- Testes realizados;
- Problemas encontrados;
- Resultados obtidos;
- Comparação entre Ubuntu e Fedora.

## Comparação

Ao final do projeto, as distribuições serão comparadas considerando diferentes aspectos:

- Facilidade de instalação;
- Facilidade de uso;
- Interface gráfica;
- Desempenho em máquina virtual;
- Gerenciamento de pacotes;
- Disponibilidade de ferramentas de desenvolvimento;
- Instalação de programas;
- Execução de códigos;
- Documentação e suporte da comunidade;
- Dificuldades encontradas.

A comparação será baseada principalmente nos testes práticos realizados durante o projeto, e não apenas nas características apresentadas pela documentação das distribuições.

---

## Resultados esperados

Espera-se identificar as principais diferenças entre Ubuntu e Fedora e verificar como cada distribuição se comporta em tarefas comuns de utilização e desenvolvimento.

Também será analisada a facilidade de configuração do ambiente, instalação de ferramentas e execução de programas e códigos.

A partir dos resultados, será possível identificar pontos positivos e limitações de cada distribuição para um ambiente voltado ao desenvolvimento de software.
