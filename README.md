# Testes e Comparação de Distribuições Linux

## Sobre o projeto

Este projeto tem como objetivo realizar testes práticos com duas distribuições Linux: **Ubuntu** e **openSUSE**. A proposta é analisar suas características, formas de utilização, ferramentas disponíveis e comportamento durante atividades práticas.

Os testes serão realizados em máquinas virtuais, permitindo utilizar os sistemas de forma segura e controlada, sem modificar o sistema operacional principal do computador.

Além da pesquisa teórica, serão realizados testes com comandos do terminal, instalação de programas e execução de códigos, buscando identificar as principais diferenças entre as duas distribuições.

---

## Objetivos

### Objetivo geral

Utilizar e comparar as distribuições Linux **Ubuntu** e **openSUSE**, analisando suas características, funcionalidades e facilidade de uso em diferentes tarefas, especialmente relacionadas ao desenvolvimento de software.

### Objetivos específicos

- Identificar o perfil de uso do Ubuntu e do openSUSE;
- Pesquisar os requisitos mínimos dos sistemas;
- Analisar seus ambientes gráficos;
- Instalar as distribuições em máquinas virtuais;
- Testar comandos básicos do terminal;
- Testar criação e navegação entre pastas;
- Testar a abertura e instalação de programas;
- Verificar a execução de códigos em Python e C;
- Registrar problemas encontrados durante os testes;
- Comparar os resultados obtidos;
- Documentar todo o processo realizado.

---

## Distribuições escolhidas

### Ubuntu

O Ubuntu é uma distribuição Linux baseada no Debian e conhecida pela facilidade de uso, ampla comunidade e grande quantidade de documentação disponível.

Foi escolhido por ser uma distribuição bastante utilizada em computadores pessoais, ambientes acadêmicos e desenvolvimento de software. Possui suporte a diversas linguagens de programação, ferramentas, bibliotecas e ambientes de desenvolvimento.

### openSUSE

O openSUSE é uma distribuição Linux desenvolvida dentro do ecossistema SUSE. A distribuição oferece diferentes ferramentas para administração e configuração do sistema e pode ser utilizada tanto em computadores pessoais quanto em ambientes de desenvolvimento.

Foi escolhido para permitir uma comparação com o Ubuntu, principalmente em relação ao gerenciamento do sistema, instalação de programas, ferramentas disponíveis e experiência de uso.

### Justificativa da escolha

Ubuntu e openSUSE foram escolhidos por serem distribuições Linux de uso geral que também oferecem recursos adequados para desenvolvimento de software.

A comparação entre as duas permite observar diferentes características e ferramentas dentro do ecossistema Linux, principalmente em relação à instalação de programas, gerenciamento de pacotes, configuração do sistema e utilização do ambiente de desenvolvimento.

## Virtualização

Para realizar os testes, serão utilizadas máquinas virtuais. Dessa forma, as distribuições podem ser instaladas e testadas sem alterar o sistema operacional principal do computador.

A virtualização também facilita a repetição dos testes e permite manter um ambiente controlado para comparar os dois sistemas.

### Ferramenta utilizada

- VMware

## Etapas do projeto

### 1. Planejamento

Nesta etapa foram definidas as distribuições que serão analisadas e a organização geral do projeto.

- Escolha das distribuições Linux;
- Definição do nicho/objetivo das distribuições;
- Pesquisa dos requisitos mínimos;
- Escolha da ferramenta de virtualização.

### 2. Pesquisa

Serão pesquisadas informações sobre cada distribuição, incluindo:

- Histórico;
- Características principais;
- Perfil de uso;
- Requisitos do sistema;
- Ambiente gráfico;
- Ferramentas de desenvolvimento;
- Gerenciamento de pacotes;
- Principais recursos.

### 3. Instalação

As distribuições serão instaladas em máquinas virtuais.

Nesta etapa serão realizados:

- Instalação e configuração do VMware;
- Criação das máquinas virtuais;
- Instalação do Ubuntu;
- Instalação do openSUSE;
- Configuração inicial dos sistemas;
- Registro de problemas encontrados.

### 4. Testes e demonstração

Após a instalação, serão realizados testes práticos nas duas distribuições.

Os testes incluem:

- Execução de comandos básicos do terminal;
- Criação de diretórios;
- Navegação entre pastas;
- Criação e manipulação de arquivos;
- Abertura de programas;
- Instalação de programas;
- Execução de código Python;
- Execução de código C;
- Testes relacionados ao ambiente de desenvolvimento.

Os resultados serão registrados para possibilitar uma comparação entre Ubuntu e openSUSE.

### 5. Relatório

Ao final dos testes, serão documentados:

- Características de cada distribuição;
- Perfil de uso;
- Processo de instalação;
- Ambiente de virtualização;
- Testes realizados;
- Problemas encontrados;
- Resultados obtidos;
- Comparação entre Ubuntu e openSUSE.

## Comparação

Após a realização dos testes, Ubuntu e openSUSE serão comparados considerando aspectos como:

- Facilidade de instalação;
- Facilidade de uso;
- Interface gráfica;
- Desempenho na máquina virtual;
- Gerenciamento de pacotes;
- Instalação de programas;
- Disponibilidade de ferramentas de desenvolvimento;
- Execução de códigos;
- Configuração do sistema;
- Documentação e suporte;
- Dificuldades encontradas.

A comparação será baseada tanto nas informações pesquisadas quanto na experiência prática obtida durante os testes.
